# Eco Pulse PWA & Tunnel Setup

## 🚀 One-Click PWA
1.  **Start the App**: Run `eco_pulse_app.py`.
2.  **Start the Tunnel**: Double-click `START_PULSE_TUNNEL.bat`.
3.  **Install**: Copy the `https://...` link and open it in Chrome/Edge/Mobile to see the Install prompt.

## 📁 Files Included
- `eco_pulse_app.py`: The core application.
- `START_PULSE_TUNNEL.bat`: Quick tunnel activator.
- `DOWNLOAD_CLOUDFLARED.ps1`: Automated installer helper.
- `cert.pem`: Project identity certificate (Placeholder).
- `logo.png`: Premium PWA icon.

## 🔧 Troubleshooting
- If "Install" doesn't show on `localhost`, clear your browser cache (F12 > Application > Storage > Clear site data).
- Ensure the tunnel uses the **HTTPS** link provided by Cloudflare.
